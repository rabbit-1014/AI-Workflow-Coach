# Workflow 内容知识库

> 作用：为路线生成提供可检索的 workflow 依据。
> 边界：本文件只沉淀 3 类高频需求的最小可执行路线，不写成工具百科，也不追求覆盖所有 AI 场景。

---

# A. 学习辅助

## 典型最小闭环

目标诊断 -> 学习资源/计划 -> 练习/任务 -> 即时反馈 -> 复盘与迭代

最低闭环不是“生成一份学习计划”，而是用户能完成一次学习任务、拿到反馈，并知道下一轮该改什么。

## 路径模式 1：AI 学习计划

- 适用场景：用户想学习 AI、英语、考试科目、技能课程，但不知道如何安排。
- 目标产物：一份可执行的 7 天或 14 天学习计划。
- 关键中间产物：当前水平诊断、学习目标、每日任务表、练习清单、复盘模板。

### 推荐阶段

1. 目标诊断
   - 做什么：明确学习目标、当前水平、可投入时间和截止日期。
   - 产出：学习画像和目标边界。
   - 最低验收：能说清“学什么、为谁学、多久学、每天多少时间”。
2. 拆学习模块
   - 做什么：把目标拆成 3 到 5 个知识模块或能力模块。
   - 产出：模块清单和优先级。
   - 最低验收：每个模块都能对应一个可练习任务。
3. 生成每日任务
   - 做什么：按天安排阅读、练习、输出或测试。
   - 产出：每日任务表。
   - 最低验收：用户每天 30 到 90 分钟内能完成。
4. 设置反馈方式
   - 做什么：为每个任务设计检查题、输出要求或自测标准。
   - 产出：练习题、检查清单、评分口径。
   - 最低验收：不是只看完资料，而是能判断是否学会。
5. 复盘迭代
   - 做什么：记录完成情况、错题和下轮调整。
   - 产出：复盘模板和下一轮计划。
   - 最低验收：能根据错题或未完成项调整下一天任务。

## 路径模式 2：AI 背单词工具

- 适用场景：用户想做背单词、词汇复习、错词回顾类小工具。
- 目标产物：一个能跑通“导入词汇 -> 练习 -> 反馈 -> 复习”的 MVP。
- 关键中间产物：词库字段、练习题样例、记忆反馈模板、错词复习规则。

### 推荐阶段

1. 定义词库和用户
   - 产出：词库范围、用户水平、每日词量。
   - 最低验收：词库不是泛泛“英语单词”，而是明确到考试、教材或主题。
2. 设计学习卡片
   - 产出：单词、释义、例句、发音、助记、难度字段。
   - 最低验收：每张卡片能支持一次学习和一次复习。
3. 生成练习任务
   - 产出：选择题、填空题、例句理解题或拼写题。
   - 最低验收：至少 10 个词能生成可直接使用的练习样例。
4. 做即时反馈
   - 产出：答错解释、记忆提示、相似词提醒。
   - 最低验收：反馈能指出错因，而不是只说“答错了”。
5. 设置复习规则
   - 产出：错词本、间隔复习规则、每日回顾任务。
   - 最低验收：用户第二天能看到需要复习的词。

## 路径模式 3：AI 学习打卡/反馈助手

- 适用场景：用户想记录学习、让 AI 根据学习记录给建议。
- 目标产物：一个表格、Notion 或低代码原型，能连续记录和反馈。
- 关键中间产物：打卡字段、反馈模板、周复盘模板、调整规则。

### 推荐阶段

1. 明确记录对象
   - 产出：学习科目、任务类型、完成标准。
   - 最低验收：知道每天要记录什么字段。
2. 搭建打卡表
   - 产出：日期、任务、时长、完成情况、问题、下一步。
   - 最低验收：用户能在 1 分钟内完成一次记录。
3. 生成 AI 反馈
   - 产出：事实总结、问题判断、明日建议。
   - 最低验收：反馈必须引用当天记录，不凭空鼓励。
4. 周复盘
   - 产出：完成率、卡点、下周调整。
   - 最低验收：能看出哪类任务最容易拖延或出错。
5. 迭代任务难度
   - 产出：加量、减量或换方法建议。
   - 最低验收：下一周计划比上一周更贴近实际完成能力。

# B. 内容创作

## 典型最小闭环

选题/受众 -> 草稿/素材生成 -> 包装 -> 发布 -> 数据反馈/复盘

最低闭环不是“写一篇文案”，而是形成一条能发布、能观察数据、能迭代下一篇的内容流程。

## 路径模式 1：小红书图文笔记

- 适用场景：用户想用 AI 做小红书图文、经验帖、工具推荐、学习笔记。
- 目标产物：一篇可发布的小红书图文笔记。
- 关键中间产物：选题卡、正文草稿、首图标题、配图清单、标签和发布复盘。

### 推荐阶段

1. 选题和受众
   - 产出：目标人群、痛点、笔记承诺。
   - 最低验收：一句话说清“谁看、解决什么问题”。
2. 搭正文结构
   - 产出：开头钩子、步骤正文、避坑提醒、结尾引导。
   - 最低验收：正文不是泛泛介绍，而是有可操作步骤。
3. 生成配图/素材
   - 产出：首图、步骤图、对比图或清单图。
   - 最低验收：每张图都对应正文中的一个信息点。
4. 包装标题和封面
   - 产出：3 个标题、1 个首图文案、版式方向。
   - 最低验收：手机列表尺寸下能看清主题和收益。
5. 发布和复盘
   - 产出：发布时间、标签、首小时数据记录、下一篇调整。
   - 最低验收：至少记录曝光、点击、收藏或评论中的 2 项。

## 路径模式 2：文案生成/改写

- 适用场景：用户需要广告文案、产品介绍、社群文案、短视频口播稿。
- 目标产物：一组可测试的文案版本。
- 关键中间产物：目标人群、卖点清单、语气样例、版本对比表。

### 推荐阶段

1. 明确文案任务
   - 产出：使用场景、目标动作、受众、限制。
   - 最低验收：知道文案是为了点击、购买、报名、私信还是转发。
2. 提炼卖点
   - 产出：功能卖点、情绪收益、信任依据。
   - 最低验收：至少有 3 个可验证或可感知的卖点。
3. 生成多版本
   - 产出：痛点型、结果型、故事型或对比型文案。
   - 最低验收：不同版本不是同义改写，而是角度不同。
4. 检查口吻和风险
   - 产出：违和表达、夸大承诺、敏感词修改。
   - 最低验收：文案符合平台和品牌语气。
5. 小范围测试
   - 产出：测试渠道、观察指标、保留版本。
   - 最低验收：能根据点击、回复或转化选出更好版本。

## 路径模式 3：内容创作闭环

- 适用场景：用户想持续产出内容，而不是只做单篇。
- 目标产物：一套可复用的内容生产流程。
- 关键中间产物：选题池、素材库、发布日历、数据复盘表。

### 推荐阶段

1. 定位内容栏目
   - 产出：栏目方向、受众、内容边界。
   - 最低验收：能连续列出 10 个同栏目选题。
2. 建选题池
   - 产出：选题、关键词、用户问题、优先级。
   - 最低验收：每个选题都有用户痛点来源。
3. 批量生成草稿
   - 产出：多篇初稿或脚本草案。
   - 最低验收：每篇都能进入人工编辑，而不是需要重写。
4. 发布排期
   - 产出：发布时间表、平台格式、素材状态。
   - 最低验收：至少能安排 1 周内容。
5. 数据复盘
   - 产出：表现好的标题、封面、主题和下一轮选题。
   - 最低验收：下一轮选题来自数据，而不是重新凭感觉。

# C. 动漫短剧 / 漫剧 / 短视频创作

## 典型最小闭环

设定/IP 方向 -> 角色视觉一致性 -> 分镜/脚本 -> 生成/剪辑 -> 首轮验证/发布

最低闭环不是"生成几段好看的视频"，而是完成一条可测试的短剧作品；具体集数、时长和发布平台应由用户确认。

## 路径模式 1：AI 动漫短剧

- 适用场景：用户想做 AI / 动漫短剧，但尚未明确时长、集数、平台或风格。
- 目标产物：一条可启动的动漫短剧制作路线；具体时长、集数和发布平台应在第一步由用户确认。
- 新手建议：可以从较短版本开始试水，例如 30-60 秒短片或 1-2 分钟完整短剧，但这些只能作为可选建议，不能写成用户已确定需求。
- 关键中间产物：世界观一句话、主角设定、角色参考图、分镜表、镜头片段、字幕和成片。

### 推荐阶段

1. 设定/IP 方向
   - 产出：题材、主角、冲突、风格、目标平台。
   - 最低验收：一个主角、一个冲突、一个情绪钩子。
2. 角色视觉锁定
   - 产出：主角基准图、服装/发型/色彩描述、反向约束。
   - 最低验收：连续生成 3 张图仍能认出同一角色。
3. 分镜脚本
   - 产出：镜头编号、时长、画面、动作、台词、提示词。
   - 最低验收：每个镜头只表达一个主要动作。
4. 生成镜头
   - 产出：3 到 8 个短镜头素材。
   - 最低验收：镜头能按剧情顺序剪在一起。
5. 剪辑发布验证
   - 产出：字幕、配音、BGM、封面、发布标题。
   - 最低验收：用户能看懂主角是谁、发生了什么、后续内容期待点是什么。

## 路径模式 2：角色一致性工作流

- 适用场景：用户卡在角色漂移、每张图不像同一个人。
- 目标产物：一套可复用的角色视觉规范。
- 关键中间产物：角色锁定词、参考图、表情/动作扩展、禁用词。

### 推荐阶段

1. 写角色锁定卡
   - 产出：年龄、发型、脸型、服装、主色、气质。
   - 最低验收：描述控制在 80 到 120 字，核心特征稳定。
2. 生成基准图
   - 产出：正面半身、全身、表情参考。
   - 最低验收：选定 1 张主参考，不混用风格差异大的图。
3. 固定提示词模板
   - 产出：不变角色词 + 可变动作/场景词。
   - 最低验收：每次只改动作、表情或场景。
4. 测试一致性
   - 产出：同角色多动作测试图。
   - 最低验收：旁观者能判断是同一角色。
5. 用于分镜生成
   - 产出：每个镜头的角色参考和动作提示词。
   - 最低验收：角色在连续镜头中不明显漂移。

## 路径模式 3：短视频脚本到成片

- 适用场景：用户已经有主题，但缺少脚本、镜头和剪辑流程。
- 目标产物：一条可测试的短视频作品；如果用户是新手，可以选择 30-60 秒试水版本，但具体时长应由用户确认。
- 关键中间产物：脚本结构、镜头清单、素材清单、剪辑节奏表。

### 推荐阶段

1. 定义视频承诺
   - 产出：受众、主题、看完收获。
   - 最低验收：前 3 秒能说明为什么值得看。
2. 写脚本
   - 产出：开头钩子、主体信息、转折、结尾行动。
   - 最低验收：口播或字幕能在目标时长内读完。
3. 拆镜头
   - 产出：镜头时长、画面、素材来源。
   - 最低验收：每个镜头都有明确素材类型。
4. 生成和剪辑
   - 产出：视频片段、字幕、配音、BGM。
   - 最低验收：声音、字幕、画面节奏基本对齐。
5. 发布验证
   - 产出：标题、封面、发布时间、数据记录。
   - 最低验收：发布后能根据完播、互动或评论决定下一条怎么改。
