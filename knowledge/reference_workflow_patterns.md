# 高质量 Workflow 参考骨架

> 作用：作为人工判断路线质量的简洁参照。
> 用法：看生成路线是否覆盖对应需求桶的关键阶段、产物和最低验收。

---

# A. 学习辅助类

## 骨架

1. 目标诊断
   - 产物：目标、水平、时间、验收方式
   - 验收：知道学什么、多久学、学到什么程度
2. 学习资源/计划
   - 产物：模块拆分、每日任务、资源清单
   - 验收：每天任务可在实际时间内完成
3. 练习/任务
   - 产物：练习题、输出任务、测试样例
   - 验收：不是只阅读，有可检查结果
4. 即时反馈
   - 产物：错因、修改建议、下一步练习
   - 验收：反馈引用用户表现，不是泛泛鼓励
5. 复盘与迭代
   - 产物：完成记录、错题/问题、调整后的计划
   - 验收：下一轮任务基于上一轮结果调整

---

# B. 内容创作类

## 骨架

1. 选题/受众
   - 产物：目标人群、痛点、内容承诺
   - 验收：一句话说清谁为什么要看
2. 草稿/素材生成
   - 产物：正文、脚本、素材清单
   - 验收：内容有结构、有例子、有可执行信息
3. 包装
   - 产物：标题、封面、版式、标签
   - 验收：首屏能看清主题和收益
4. 发布
   - 产物：平台格式、发布时间、发布版本
   - 验收：内容满足目标平台基本格式
5. 数据反馈/复盘
   - 产物：表现数据、问题判断、下一篇调整
   - 验收：下一轮内容能引用数据依据

---

# C. 动漫短剧 / 漫剧 / 短视频类

## 骨架

1. 设定/IP 方向
   - 产物：主角、题材、冲突、风格、平台
   - 验收：一个主角、一个冲突、一个情绪钩子
2. 角色视觉一致性
   - 产物：角色锁定卡、基准图、提示词模板
   - 验收：多张图仍能认出同一角色
3. 分镜/脚本
   - 产物：镜头表、台词、动作、时长、提示词
   - 验收：每个镜头只表达一个主要动作
4. 生成/剪辑
   - 产物：镜头片段、字幕、配音、BGM、成片
   - 验收：镜头顺序能讲清一个完整事件
5. 首轮验证/发布
   - 产物：标题、封面、发布版本、反馈记录
   - 验收：能判断角色、剧情或节奏下一轮该改什么
