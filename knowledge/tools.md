# 工具知识卡片

> 作用：为 3 类需求提供轻量工具选择依据。
> 边界：本文件不是工具百科。每个工具必须绑定到具体步骤、产出和轻量替代。

---

# A. 学习辅助

## 常用工具组合

### ChatGPT / 通义千问

- 常用步骤：目标诊断、学习计划、练习生成、即时反馈、错题解释。
- 适合产出：学习画像、每日任务、练习题、答题反馈、复盘建议。
- 轻量替代：豆包、Kimi。
- 最小用法：让模型按“目标、当前水平、每日时间、练习、验收”输出，不只生成鼓励性计划。

### Kimi

- 常用步骤：资料阅读、课程笔记整理、长文总结、错题归纳。
- 适合产出：知识框架、重点摘要、易错点、复习清单。
- 轻量替代：ChatGPT 文件阅读、通义千问文档理解。
- 最小用法：先上传或粘贴资料，再要求按考试、任务或章节重组。

### Notion / 飞书表格 / Excel

- 常用步骤：学习打卡、词库管理、复盘记录。
- 适合产出：打卡表、错词本、复习计划表、完成率统计。
- 轻量替代：普通表格、纸质记录。
- 最小用法：先做可手动维护的表，再考虑自动化。

### Quizlet / Anki

- 常用步骤：单词卡片、间隔复习、错词回顾。
- 适合产出：词卡、复习队列、记忆反馈。
- 轻量替代：飞书表格 + ChatGPT 生成练习。
- 最小用法：先导入 20 到 50 个词测试复习节奏。

# B. 内容创作

## 常用工具组合

### ChatGPT / 通义千问

- 常用步骤：选题、标题、正文草稿、文案改写、发布复盘。
- 适合产出：选题池、图文大纲、口播稿、标题版本、复盘分析。
- 轻量替代：豆包、Kimi。
- 最小用法：输入受众、平台、内容目标和参考风格，要求多版本对比。

### Kimi

- 常用步骤：参考资料整理、竞品内容分析、长文压缩。
- 适合产出：素材摘要、观点清单、可引用资料、内容结构。
- 轻量替代：ChatGPT 文件阅读。
- 最小用法：把参考内容整理为“可用观点、案例、禁用表达”。

### Canva / 稿定设计

- 常用步骤：封面、长图、信息图、发布素材包装。
- 适合产出：小红书首图、步骤图、对比图、海报。
- 轻量替代：小红书内置编辑器、PPT。
- 最小用法：用模板先确定层级，再替换标题和素材。

### 即梦 / 豆包图像 / Midjourney

- 常用步骤：配图、封面背景、风格图、示意图。
- 适合产出：封面图、插图、视觉素材。
- 轻量替代：Canva 素材库、截图标注。
- 最小用法：不要直接生成整张封面，先生成主视觉，再进入排版工具加标题。

### 平台数据面板

- 常用步骤：发布后复盘。
- 适合产出：曝光、点击、收藏、评论、转化线索。
- 轻量替代：手工记录表。
- 最小用法：每篇至少记录标题、封面、发布时间和 2 个表现指标。

# C. 动漫短剧 / 漫剧 / 短视频创作

## 常用工具组合

### ChatGPT / 通义千问

- 常用步骤：设定、剧情大纲、分镜脚本、提示词、字幕和标题。
- 适合产出：角色设定、世界观一句话、分镜表、镜头提示词、旁白。
- 轻量替代：豆包。
- 最小用法：要求输出分镜表，字段包含镜头、时长、画面、动作、台词、提示词。

### 即梦 / Midjourney / 豆包图像

- 常用步骤：角色视觉、场景图、关键帧、封面图。
- 适合产出：角色基准图、表情图、场景参考、首图。
- 轻量替代：平台素材库、手绘草图。
- 最小用法：先生成角色基准图，再复用角色描述和参考图，不要每个镜头重新发明角色。

### 可灵 / Runway / Pika / 即梦视频

- 常用步骤：图生视频、文生视频、短镜头生成。
- 适合产出：3 到 5 秒镜头片段、动作镜头、转场素材。
- 轻量替代：静态图 + 剪映运镜。
- 最小用法：优先图生视频，输入明确单一动作，避免一个镜头塞多个动作。

### 剪映 / CapCut

- 常用步骤：剪辑、字幕、配音、BGM、封面导出。
- 适合产出：完整成片、字幕轨、口播配音、发布版本。
- 轻量替代：手机相册剪辑、平台内置剪辑器。
- 最小用法：先把镜头按剧情顺序剪成无声版本，再加字幕、配音和音乐。

### ElevenLabs / 剪映文本朗读

- 常用步骤：配音、角色旁白、口播。
- 适合产出：旁白音频、角色台词、不同声线版本。
- 轻量替代：剪映默认朗读、真人临时配音。
- 最小用法：短剧首版可先用剪映文本朗读，不必一开始追求高成本声线。
